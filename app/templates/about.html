About this project

MediBook is a Doctor Appointment Booking System built as a Database Management Systems (DBMS) AAT mini-project. It demonstrates a normalized MySQL schema with primary keys, foreign keys, CHECK constraints, a UNIQUE constraint that prevents double booking, indexes and transactions, connected to a Flask web application.

Technology

  • Frontend: HTML5, CSS3, vanilla JavaScript
  • Backend: Python 3 and Flask
  • Database: MySQL (parameterized queries)

Important notice

This is an academic demonstration. Doctor records are fictional sample data. It has not had a security assessment and is not intended for real patient data.
